# 寻幽

小巧美观的 PC 端 TXT 小说阅读器。

## 特点

- 按可视区域分页，支持 3D 翻页
- 自动识别章节目录，记忆阅读进度
- 书签、阅读历史、本地书库
- 自动检测文本编码，乱码时可对照预览切换
- 明暗主题，字体 / 字号 / 行高可调
